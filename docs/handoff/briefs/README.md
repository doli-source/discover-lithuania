# Briefs

One file per open question. Name it for the question, not the topic.

The five questions worth researching are in section 6 of
`../SESSION-2026-09-20.md`, with the numbers behind each. In short:

1. Why does `/blog/best-restaurants-vilnius` sit at position 13 for a query
   with 458 impressions, all from inside Lithuania?
2. Three Backstage branches split 1,260 impressions at positions 24–53 and
   convert none. One page or three?
3. Branded restaurant queries rank 6–11 and get zero clicks. Is that structural?
4. Is the "near me" cluster winnable against a local map pack?
5. What would page one for `וילנה` actually cost, given no new content?

## What a useful brief contains

- The question, in one sentence.
- The numbers it starts from, with the country split. An impression total that
  has not been split by country is not evidence.
- What was checked, including what was ruled out.
- A recommendation, and what would have to be true for it to be wrong.

## What to avoid

Do not recommend anything that requires writing site content — the owner has
ruled that out, and a brief that ignores the constraint is not actionable. If
the honest answer is "this needs content", say that plainly and cost it.
